# O que o computador está procurando na imagem para decidir que aquilo é um rosto?
- No caso o meu programa, procura por caracteristicas como, olhos, nariz, boca para determinar o que é um rosto.

# O que acontece se você cobrir a boca ou os olhos? O algoritmo ainda funciona?
- Não, o programa utiliza essas caracteristicas faciais para determinar o que é um rosto, para tal feito seria nescessario uma melhoria no codigo do programa para determinar o que é um rosto.

# A diferença entre detectar (saber que há um rosto) e reconhecer (saber de quem é o rosto)?
- Detectar é reconhecer as caracteristicas que compoem um rosto, reconhecer é saber que aqueles conjustos de caracteristicas respondem a um determinado rosto.

# Distancia
- Aparentemente o programa consegue detectar rostos a uma distancia rasoavel, mas qualidade da camera, movimento, iluminação, angulo e objetos no rosto podem afetar o resultado.

# Acessórios
- Oculos normar não afetam a detecção, mas objetos como oculos escuros ou mascaras por cobrirem caracteristicas essenciais do rosto podem afetar a detecção.

# Perfil
- Como mencionado anteriormente, angulos como rosto de perfil podem afetar a detecção de rosto.

# Múltiplas faces
- Sim, o programa consegue detectar multiplos rostos, mas a aproximação, profundidade ou iluminação podem afetar a detecção.
